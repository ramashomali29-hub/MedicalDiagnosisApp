# MedicalDiagnosisApp

MedicalDiagnosisApp is an ASP.NET Core MVC application that evaluates selected symptoms and displays the most likely condition.

## Features

* Two-stage symptom assessment
* General and detailed symptom selection
* Emergency symptom detection
* Disease results based on symptom weights
* Input validation
* SQL Server database integration

## Technologies

* ASP.NET Core MVC
* C#
* Entity Framework Core
* SQL Server
* HTML, CSS, and Bootstrap

## Purpose

This project was created to practise MVC architecture, database relationships, form validation, and data processing.

**Disclaimer:** This application is for educational purposes only and does not replace professional medical diagnosis.
